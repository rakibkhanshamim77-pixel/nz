  PART 1 — ISSUES FOUND IN EXISTING IMPLEMENTATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  BUG 1 (Critical) — metadataBase crash
    File: app/layout.tsx
    Problem: `new URL(process.env.NEXT_PUBLIC_SITE_URL || "")` throws
             TypeError at build time when env var is unset.
    Fix: fallback changed to "https://neeshanz.com"

  BUG 2 (Critical) — Wrong global canonical
    File: app/layout.tsx
    Problem: `alternates: { canonical: "/" }` in root layout propagates
             to every page that does not override it, making Google see
             ALL pages as canonically the homepage.
    Fix: Each indexable page now sets its own canonical; private/transactional
         pages inherit "/" which is acceptable (they're noindex anyway).

  BUG 3 (High) — OG description mismatch
    File: app/layout.tsx
    Problem: OG description was "Shop Neeshanz for trendy fashion…" —
             not the official brand description.
    Fix: Updated to official "Discover premium T-shirts that blend
         modern style, comfort & confidence…"

  BUG 4 (High) — Wrong OG locale
    File: app/layout.tsx
    Problem: `locale: "bn_BD"` — spec requires `en_BD` for English content
             targeting Bangladesh market.
    Fix: Changed to `en_BD`

  BUG 5 (High) — Twitter description mismatch
    File: app/layout.tsx
    Problem: Twitter description was "Premium quality t-shirts with
             modern designs." — different from OG and official.
    Fix: Both Twitter and OG now use official description.

  BUG 6 (High) — No robots.ts or sitemap.ts
    Problem: Google had no crawl guidance and no structured URL list.
    Fix: Created app/robots.ts and app/sitemap.ts (see files created).

  BUG 7 (High) — Admin panel fully indexable
    File: app/(admin)/layout.tsx
    Problem: No robots directive on admin layout → all 18 admin pages
             were indexable by default.
    Fix: Added `export const metadata` with robots: noindex, nofollow
         to admin layout (applies to all 18 admin pages at once).

  BUG 8 (High) — Auth page fully indexable
    File: app/(auth)/layout.tsx
    Problem: Login page had no noindex.
    Fix: Same approach as admin — added metadata export to auth layout.

  BUG 9 (Medium) — Transactional pages fully indexable
    Files: cart, checkout, payment, order-success, track-order, my-account
    Problem: These pages had no robots directive and inherited the global
             index:true from root layout.
    Fix: robots: { index: false, follow: false } added to each.

  BUG 10 (Medium) — Indexable pages missing canonical
    Files: shop, privacy-policy, terms-and-conditions, size-guide
    Problem: These pages had metadata but no alternates.canonical,
             so they inherited canonical "/" from root layout.
    Fix: Correct page-level canonical added to each.

  BUG 11 (Medium) — Product title lacks brand/location context
    File: app/(main)/product/[slug]/page.tsx
    Problem: Title was just `product.name` with no brand suffix.
    Fix: Title is now `{product.name} in Bangladesh | Neeshanz`

  BUG 12 (Medium) — Product description truncated mid-word
    File: app/(main)/product/[slug]/page.tsx
    Problem: `product.description.slice(0, 160)` cuts at byte position,
             not at a word boundary.
    Fix: `truncateAtWord()` helper added; truncates at last space ≤ 155
         chars and appends "…"

  BUG 13 (Low) — ProductJsonLd uses relative URL
    File: app/(main)/components/product/ProductJsonLd.tsx
    Problem: `offers.url` was a relative path like `/product/slug`.
             Schema.org requires an absolute URL.
    Fix: Absolute URL constructed from NEXT_PUBLIC_SITE_URL env var.

  BUG 14 (Low) — Product JSON-LD missing brand entity
    File: app/(main)/components/product/ProductJsonLd.tsx
    Problem: No `brand` field in Product schema.
    Fix: Added `brand: { "@type": "Brand", name: "Neeshanz" }`

  BUG 15 (Low) — Cart page had zero metadata
    File: app/(main)/cart/page.tsx
    Problem: No metadata at all — not even a title.
    Fix: Added title + robots: noindex
